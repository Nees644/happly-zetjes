# ikhoudvol.nl

Statische site van de reeks Ik houd vol. Los Vercel-project met als Root Directory `ikhoudvol`; staat in deze repository maar wordt niet door de Zetjes-app geserveerd (die serveert alleen `public`).

- `index.html`: de reeks. Nieuwe aflevering: één regel in `AFLEVERINGEN` en de bestanden in `afleveringen/`.
- `opnemen.html` (ikhoudvol.nl/opnemen): zinnen invullen, opnemen met autocue onder de camera, terugkijken, versturen. De opname blijft op de telefoon; er gaat niets naar een server.
- Montage en draaiboek staan buiten de repository in het startpakket.
